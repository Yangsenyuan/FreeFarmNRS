## 5. 元数据冲突

同一 Scene 的简化 JSON 中 `cloud_cover` 为 `0`，而产品 XML 中的 `cloudCoverPercentage` 为 `31.27`。平台不应静默选择一个值并隐藏另一个值，应：

1. 分别保存两个原始值及其来源。
2. 在影像详情中显示冲突提示。
3. 等待用户确认最终采用的云量。
4. 不因冲突阻止基础影像查看和光谱查询。

## 6. 展示与材料边界

- 该数据仅用于用户本地平台展示和用户软著材料。
- 不把 PlanetScope 原始数据复制到无关工作目录或公开发布。
- 平台内置模型基于合成数据训练；若用其对该影像生成氮素结果，必须注明“仅用于流程演示，不代表真实田间标定精度”。
- 卫星影像界面统一使用“采集日期”，不使用只适用于无人机的“飞行日期”。
- 软件说明书中应注明影像编号、采集时间和用户提供的数据来源。

## 7. 本地平台实现与验收结果

- 独立项目：`planet_hengyu_case` / `planet_hengyu_img1`。
- 原始裁剪影像与三份同名侧车只保存在 `data/projects/planet_hengyu_case/images/planet_hengyu_img1/source/`，未加入测试图片或公开示例目录。
- 自动解析字段的来源：传感器、仪器、采集时间、值类型和处理级别为 `xml_sidecar`；8 个中心波长与 FWHM 为 `json_sidecar`；地点为 `user`。
- 反射率转换：按比例因子 10000 处理 uint16 DN，反射率 1%–99% 分位约为 0.041–0.390。
- 植被掩膜：NDVI ≥ 0.35，有效像元 137,512 / 288,002，占 47.747%。
- 流程演示模型：`planet_nmass_demo`，复用 `dnn_nmass_demo` 的 51 波段合成 DNN 示例权重。
- 演示统计：均值 20.944 mg/g，标准差 4.911 mg/g，变异系数 23.45%；低氮/适宜/高氮占比 39.802% / 59.791% / 0.407%。
- 重采样追溯：原始 442–865 nm 的 8 波段对齐到模型 400–900 nm 的 51 波段，精确 2、插值 40、边缘填充 9，填充比例 17.647%。
- 截图：`docs/screenshots/11_planetscope_home.png` 至 `16_planetscope_results.png`。
- 专题图：`docs/examples/PlanetScope恒福菜场_流程演示专题图.png`。
- 报告：`docs/examples/PlanetScope恒福菜场_流程演示报告.pdf`。
