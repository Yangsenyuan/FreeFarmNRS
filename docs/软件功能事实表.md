# 农田氮素遥感监测与反演平台 V1.0 功能事实表

> 事实基线：2026-11-18  
> 用途：软件说明书、用户操作手册、源程序文档及软著申请书的统一事实底稿  
> 核对依据：当前源代码、需求文档、示例项目、真实 PlanetScope 本地案例、更新后的界面截图、PDF 报告，以及 2026-11-17 自动化与 API 验收记录

> 详细命令、模型指标、PlanetScope 流程结果和不支持格式见 `docs/V1.0增强验收记录.md`。

## 1. 使用说明

本表描述 V1.0 源代码中实际存在的功能，不把需求规划自动视为已实现功能。

| 状态 | 含义 |
|---|---|
| 已实现 | 有用户入口、后端实现及示例数据或历史验证记录支持 |
| 有限实现 | 已能使用，但受数据类型、算法范围、精度或交互方式限制 |
| 规划未实现 | 仅在需求文档或后续计划中出现，当前版本不能作为已实现功能宣传 |
| 环境依赖 | 功能代码存在，但需要补齐依赖、字体、模型文件或运行环境 |

当前代码事实：

- 软件名称：农田氮素遥感监测与反演平台
- 软件版本：V1.0；代码版本号 `1.0.0`
- 形态：Windows 本地单机 Web 应用，浏览器访问 `127.0.0.1`
- 前端：Vue 3、ECharts、原生 Canvas，本地文件部署，无 CDN
- 后端：FastAPI、Rasterio、NumPy、SciPy、scikit-learn、Matplotlib、ReportLab
- 自有源代码：约 61 个文件（含测试与侧车模块），约 16,448 行；源程序拼版按长行换行后为 17,350 行，不含 Vue、ECharts 第三方文件
- 示例材料：17 张当前界面截图（含 7 张 PlanetScope 案例相关）、2 张专题图、2 份 PDF 报告、2 个合成示例项目和 1 个用户提供的 PlanetScope 本地展示项目
- 版本管理：当前目录不是 Git 仓库，没有提交历史可引用
- 运行环境：`.venv` 已恢复 NumPy、SciPy、scikit-learn、Pillow、AnyIO、h11、HTTPX、pytest 与 PDF/Pdfium 测试依赖；实际导入、预处理、反演、PNG/PDF 导出均已验证

## 3. 模型部分操作事实

### 3.1 当前实际链路

```text
导入自定义模型
  → 校验波长/阈值/可信来源
  → 执行模拟输入试推理并记录 SHA-256
  → 保存到 data/models/<model_id>/
  → 进入全局模型库
  → 选择当前影像和模型
  → 服务端适用性预检
  → 必要时自动预处理
  → 执行前再次预检；硬错误阻断，警告需 force=true
  → 按模型训练波长重采样影像波段
  → 按行分块推理
  → 写入结果及模型/重采样/预处理/告警追溯摘要
```

Few-shot 后校准链路：

```text
基础模型完成当前影像结果
→ 输入实测样点 col,row,nmass
→ 从当前 Nmass 栅格读取基础预测
→ 1–2 样点偏置 / 3–4 样点收缩线性 / ≥5 样点后校准
→ 计算 MAE、RMSE、偏差、R² 与留一验证
→ 保存派生模型和校正前结果快照
→ 应用派生模型重新反演当前影像
```

### 3.2 直接问答

| 问题 | 当前答案 |
|---|---|
| 模型可以自由选择吗？ | 模型库全部显示，但“不兼容”模型禁用；警告项必须确认后才能执行。 |
| 系统会自动筛选适合当前影像的模型吗？ | 会计算状态和推荐项；可选模型仍由用户确认，推荐不是精度最优声明。 |
| 不匹配模型会被禁止运行吗？ | 模型文件缺失、输入类型不支持、波段完全无交集等硬错误始终禁止；作物/传感器等需确认警告。 |
| 可以自己上传模型吗？ | 可以，支持 `.pkl`、`.joblib` 和单输入 `.onnx`。 |
| 上传后能直接用于这期影像吗？ | 通过试推理后导入并自动选中，但仍需当前影像适用性预检和用户确认。 |
| 上传模型只对当前影像有效吗？ | 不是。模型进入全局模型库，可被任意项目选择。 |
| 平台会用这期影像重新训练模型吗？ | 不会更新父模型全部权重。已有结果后可用少量实测样点拟合偏置/斜率后校准，并保存为派生模型。 |
| few-shot 会修改原模型文件吗？ | 不会。父模型哈希和文件保持不变，派生模型仅记录父模型 ID、系数、样点和指标。 |
| 最少几个实测样点？ | 1 个可做整体偏置校正；3–4 个启用保守收缩线性校正；建议至少 5 个空间独立样点。 |
| 样点坐标是什么格式？ | CSV 使用 `sample_id,col,row,nmass`，`col`/`row` 为预处理栅格 0 基列号和行号，实测 Nmass 单位必须与当前结果单位一致。 |
| 派生模型能用于其他影像吗？ | 可以，父模型可用时会继承同样的后校准系数；但样点代表性仍限定于原作物、传感器和时空条件。 |
| 波段不一样还能运行吗？ | 会按训练波长做线性插值；超出影像范围的波段用最近边缘波段填充。 |
| 平台会验证模型精度吗？ | 不会。R²、RMSE 由用户填写或模型元数据提供，平台不重新评估。 |
| 批量反演如何选模型？ | 对选中影像使用同一模型和阈值；开始前逐幅显示兼容性表，任一幅硬不兼容默认拒绝。 |
| 换影像时模型会自动重选吗？ | 会重新预检；原模型不兼容时自动选择推荐模型，警告项要求用户确认。 |
