## 使用前准备

平台采用本地浏览器界面。推荐使用 Windows 10/11、Python 3.9 及以上版本、Chrome 或 Edge 浏览器。首次安装 Python 依赖需要访问软件包源，日常运行和数据处理在本地完成。

| 项目 | 建议要求 |
|---|---|
| 内存 | 8 GB 以上；大影像建议 16 GB 以上 |
| 磁盘 | 根据原始影像、光谱栈、结果和报告大小预留空间 |
| 浏览器 | Chrome 或 Edge 当前稳定版 |
| 网络 | 仅首次安装依赖需要 |

## 启动平台

1. 打开项目根目录。
2. 双击 `启动平台.bat`。
3. 浏览器打开 `http://127.0.0.1:8765/`。
4. 如果浏览器没有自动打开，可手动访问该地址。
5. 关闭启动窗口通常即可停止服务。

如果提示缺少依赖，请按照 `README.md` 安装 `requirements.txt`。需要运行自动化测试时安装 `requirements-dev.txt`。

## 完整业务流程

```text
新建或打开项目
→ 导入影像和元数据
→ 查看影像与光谱
→ 执行预处理
→ 选择模型和阈值
→ 执行反演
→ 查看统计与专题图
→ 导出 PNG/PDF
```

## 导入影像

进入左侧“数据导入”页面。

### GeoTIFF

- 选择一个或多个 `.tif`、`.tiff` 文件。
- 可同时选择 `.aux.xml`、JSON、XMP 等侧车文件。
- 导入完成后，平台自动读取尺寸、波段、坐标系和标签。

### ENVI

- 同时选择同名 `.hdr` 和 `.dat`、`.img`、`.bil` 或 `.bsq`。
- 缺少头文件时，页面显示文件配对提示。
- 头文件可使用 UTF-8、BOM 或 GBK/ANSI 编码。

### PlanetScope 案例

- 选择 8 波段 Surface Reflectance GeoTIFF。
- 同时选择同名 STAC JSON、简化 JSON 和产品 XML。
- 平台自动读取 Scene ID、传感器、仪器、采集时间、8 个波长、FWHM、EPSG 和反射率缩放。

## 检查元数据

导入后，在“元数据确认与数据备注”区域查看字段来源。

| 来源标记 | 含义 |
|---|---|
| 用户修改 | 用户手工确认或修改的值，优先级最高 |
| ENVI 头文件 | 来自 ENVI `.hdr` |
| GeoTIFF 标签 | 来自数据集或波段标签 |
| XML/JSON 侧车 | 来自产品 XML、STAC JSON 或其它侧车 |
| 文件名推断 | 根据文件名中的日期、田块或类型推断 |
| 待人工确认 | 未识别到可靠值 |

### 修改字段

1. 修改传感器、采集日期、田块、备注、中心波长或带宽。
2. 中心波长数量必须与波段数一致。
3. 点击“保存元数据”。
4. 修改日期或备注通常不影响已有处理结果。
5. 修改中心波长、反射率缩放或值类型后，应重新执行预处理和反演。

### 数据冲突

同一字段的不同来源值不一致时，平台保留全部观测值。例如 PlanetScope 案例的 JSON 云量为 0%，XML 云量为 31.27%。应结合产品说明确认最终采用值。

### 重新解析头文件

1. 把遗漏的侧车文件放入当前影像的 `source` 目录。
2. 点击“重新解析头文件”。
3. 查看新旧值和来源对比。
4. 确认应用方式。
5. 用户已修改的字段默认保留。

## 查看影像与光谱

进入“影像查看”并选择当前影像。

### 显示模式

- 真彩色：按红、绿、蓝中心波长选波段。
- 假彩色：突出近红外、红边和植被差异。
- 单波段：检查坏波段、云、阴影或异常像元。
- 伪彩色：用色带增强单个波段数值差异。
- 对比：用于空间范围一致或已经配准的多期影像卷帘。

### 缩放和漫游

- 鼠标滚轮或缩放按钮改变显示比例。
- 拖动画布进行漫游。
- 全屏按钮放大查看区域。

### 光谱查询

1. 选择“单点”。
2. 点击影像像元。
3. 查看右侧光谱曲线和数据表。
4. 选择“框选”并拖动鼠标，计算区域平均光谱。
5. 选择“多点”叠加比较最多五条曲线。

## 执行数据预处理

进入“数据预处理”。

### 反射率转换

- 输入 DN：按比例因子或定标系数转换。
- 输入已是 0–1 反射率：选择“不转换”。
- PlanetScope STAC 中 `scale=0.0001` 时，比例因子可设为 10000。

### 坏波段与平滑

- 按波长范围填写需要剔除的坏波段。
- 设置 Savitzky-Golay 窗口和多项式阶数。
- 波段数不足时，平台自动缩小窗口或跳过平滑。

### 波段对齐

- 设置目标起始波长、结束波长和步长。
- 默认目标为 400–900 nm、10 nm 共 51 波段。
- 超出源范围的波段采用最近边缘波段填充。
- 对齐结果记录精确、插值和边缘填充波段数。

### 掩膜和指数

- 设置 NDVI 植被掩膜阈值，默认 0.35。
- 可选择 NDVI、NDRE、CIredge、GNDVI。
- 如需云检测，可启用蓝光阈值法。
- 当前 ROI 仅支持矩形行列范围。

### 执行和检查

1. 点击“执行预处理”。
2. 查看后台任务进度。
3. 查看 RGB、NDVI 和掩膜预览。
4. 检查反射率范围、有效像元比例和波段对齐提示。

## 选择模型

进入“模型反演”页面。

1. 在左侧选择当前影像。
2. 在中间查看模型卡片。
3. 检查算法、适用作物、传感器、R²、RMSE、单位和兼容状态。
4. 选择推荐或满足要求的模型。

模型卡片可能显示：

| 状态 | 含义 |
|---|---|
| 推荐 | 当前影像与模型元数据较匹配 |
| 可重采样 | 影像波段需要插值或边缘填充 |
| 信息不足 | 作物或传感器元数据不足，需要人工确认 |
| 不兼容 | 缺少必要波段、输入类型不支持或其它硬性冲突 |

切换影像后，平台重新计算推荐和兼容性。若已选模型不适用于新影像，页面要求重新选择或确认。

## 执行单幅反演

1. 设置低氮阈值和高氮阈值。
2. 确认高氮阈值大于低氮阈值。
3. 影像未预处理时，可勾选自动执行默认预处理。
4. 查看兼容性警告和插值/边缘填充提示。
5. 点击“一键反演”。
6. 等待进度完成。
7. 点击“查看结果”。

硬性不兼容会阻止执行。一般警告需要明确确认后才能继续。强制继续的决定会写入结果追溯信息。

## 执行批量反演

1. 点击“批量反演”。
2. 勾选多幅影像。
3. 查看逐影像兼容性表。
4. 确认每幅影像的波段、处理状态和填充数量。
5. 输入统一模型和阈值。
6. 开始任务。
7. 查看成功数、失败数和逐幅错误。

批量任务使用同一模型和阈值。任一幅影像硬不兼容时默认拒绝；不支持绕过硬性错误。

## 导入自定义模型

1. 点击“导入模型”。
2. 选择 `.pkl`、`.joblib` 或单输入 `.onnx`。
3. 填写模型名称和算法。
4. 填写训练中心波长，数量与模型输入特征数一致。
5. 填写适用作物、传感器、单位、版本和说明。
6. 填写 R²、RMSE、低氮和高氮阈值。
7. 确认模型文件来源可信。
8. 点击导入。

平台会验证波长顺序、试推理输出数量、NaN/Inf 和文件哈希。试推理成功不代表模型精度或业务适用性已验证。

导入后的模型进入全局模型库，可在其他项目中选择。自定义模型本身只执行推理；如需利用少量实测样点减弱偏差，使用后续 Few-shot 后校准流程。

## 使用实测样点进行 Few-shot 校正

Few-shot 用于在基础模型完成当前影像反演后，利用少量实测 Nmass 样点减弱整体偏差或斜率误差。它不修改父模型文件。

### 准备实测样点

像素坐标 CSV：

```text
sample_id,col,row,nmass
s1,120,80,23.4
s2,240,96,25.1
s3,360,144,21.8
s4,420,210,26.0
s5,510,260,27.3
```

可直接使用模板 `../examples/few_shot_samples_template.csv`。

如果实测点带 GPS 经纬度，可使用：

```text
sample_id,lon,lat,nmass
s1,114.17650,23.01480,23.4
s2,114.17800,23.01420,25.1
s3,114.17920,23.01360,21.8
```

可使用经纬度模板 `../examples/few_shot_samples_lonlat_template.csv`。

平台将 WGS84 经纬度转换为当前结果 CRS 下的行列号。像素坐标与经纬度任选一种，不要在同一行混填两套坐标。

- `col`、`row` 是预处理结果栅格的 0 基列号和行号。
- `nmass` 必须为有限正数。
- 实测单位必须与当前结果单位一致。
- 样点应位于有效植被掩膜内。
- 建议至少准备 5 个空间上相互独立的样点。

### 操作步骤

1. 先使用模型库中的基础模型完成当前影像反演。
2. 进入“结果分析”。
3. 点击“实测微调”。
4. 选择“像元坐标”或“经纬度”，下载对应 CSV 模板并按列填写实测样点。
5. 上传 CSV 或手动录入样点。
6. 查看样点表、基础预测值、实测值、残差和无效样点原因。
7. 查看校正模式、斜率、截距及校正前后指标。
8. 确认后点击“应用并重新反演”。
9. 等待后台任务完成，查看新的结果与校正追溯。

>
> 文件：`../screenshots/17_fewshot_modal.png`

### 校正规则

- 1–2 个有效样点：只校正整体偏差。
- 3–4 个有效样点：使用向斜率 1 收缩的保守线性校正。
- 5 个及以上：拟合偏置与斜率后校准。

平台同时显示样本内指标和留一验证指标。样本内改善不等于独立精度，建议结合空间独立样点和独立验证数据判断。

### 父模型与派生模型

- 父模型文件不变。
- 派生模型记录父模型 ID、父模型哈希、样点、系数、单位、样点指纹和指标。
- 被派生模型引用的自定义父模型不能直接删除。
- 校正前结果保存在 `results/calibration_sources/<model_id>/`。

校正前的数据样例：

```text
├── latest.json
├── nmass_latest.npy
├── nmass_*.tif
└── previews/
```

### 当前边界

Few-shot 是通用后校准，不是对 PLSR、随机森林、SVR 或 DNN 全部权重的重新训练。样点数量少、空间代表性不足或与目标影像作物/传感器不一致时，结果仍可能产生偏差。

## 常见问题

### 影像没有中心波长

检查 ENVI 头文件、GeoTIFF 标签或侧车文件。重新解析仍无法获得时，按波段顺序手工填写中心波长和可选 FWHM。

### 模型显示不兼容

检查当前影像波段、模型训练波长、作物和传感器。硬性不兼容不能通过前端警告绕过。

### 结果几乎全为一个等级

检查反射率缩放、中心波长顺序、植被掩膜、模型单位和阈值。内置模型只用于流程演示。

### PDF 无法生成

检查中文字体和 ReportLab 依赖。PNG 专题图仍可单独导出。

### 服务无法启动

检查 Python 依赖、端口占用和启动窗口中的错误信息。

### 为什么自定义模型不能只属于当前影像

当前模型库为全局作用域。项目级或影像级模型作用域仍在后续优化清单中。
