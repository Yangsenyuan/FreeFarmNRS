## 设计目标

V1.0 采用本地单机部署，将影像、模型、参数和结果保存在可迁移的项目目录中。前后端通过本地 HTTP API 解耦，业务算法集中在服务层，接口层只负责参数校验、任务提交和响应封装。

设计重点包括：

- 数据可追溯。
- 模型适用性显式化。
- 不同传感器波段可对齐。
- 长耗时任务可观察。
- 专题图和报告可重复生成。
- 用户手工元数据不被自动解析覆盖。

## 项目数据模型

项目以唯一 ID 标识。`project.json` 保存名称、描述、作物、地点、备注、时间、影像数组和每幅影像的最新处理摘要。

| 对象 | 关键字段 | 用途 |
|---|---|---|
| Project | id、name、crop、field、note、created_at、images | 项目及业务上下文 |
| Image | id、file、format、sensor、flight_date、width、height、bands、crs、wavelengths、status | 影像索引和展示 |
| Metadata | value、source、confidence、raw_key、raw_value | 字段级来源追溯 |
| ProcessedMeta | config、shape、wavelengths、mask、indices、quality、previews | 预处理结果和参数 |
| ResultSummary | stats、class_stats、histogram、model、trace、files、unit | 结果统计和报告依据 |
| ModelMeta | id、algorithm、wavelengths、file、file_sha256、metrics、limitations | 模型运行和追溯 |

预处理光谱栈使用压缩 NPZ 保存，掩膜和结果使用 NPY。反演结果同时输出 GeoTIFF 单波段栅格，保留坐标系、仿射变换和 nodata。

每次反演生成新栅格，`latest.json` 保存最新一次摘要，项目级 `results_history.json` 保存用于多期对比的统计摘要。

## 影像元数据解析设计

元数据解析器将不同来源归一化为统一字段，同时保留原始键名、原始值和来源。优先级从高到低为：

1. 用户修改。
2. 栅格数据集标签。
3. ENVI 头文件。
4. 厂商侧车。
5. 文件名规则。
6. 默认值。

### 支持的输入

- ENVI `.hdr`，包括 BOM、UTF-8、GBK/ANSI 编码回退。
- GeoTIFF 数据集标签和波段标签。
- GDAL AUX XML。
- 通用 JSON。
- MicaSense 结构 XMP 测试样例。
- PlanetScope PSScene STAC JSON、简化 JSON 和产品 XML。
- 文件名中的日期、田块和光谱类型线索。

### 解析步骤

| 步骤 | 处理 |
|---|---|
| 发现文件 | 识别同名 ENVI 头文件、AUX XML、XMP、JSON 和 TIFF 标签 |
| 提取字段 | 读取尺寸、坐标、光谱、传感器、时间和产品信息 |
| 单位归一 | 微米等波长单位转换为 nm，反射率缩放单独保存 |
| 来源合并 | 按优先级合并，用户值优先；冲突值保留列表 |
| 业务映射 | 映射为 sensor、date、field、image_type 和 value_type |
| 确认保存 | 用户可修改；重新解析时展示新旧值，不静默覆盖 |

### 冲突处理

同一字段出现不同来源值时，系统保存全部观测并生成冲突提示。PlanetScope 案例的 JSON 云量为 0%，XML 云量为 31.27%，平台保留双来源，不在后台静默选择单一值。

## 模型兼容性设计

兼容性服务接收影像元数据、预处理元数据和模型元数据，返回：

- 状态、错误和警告。
- 作物匹配和传感器匹配。
- 输入类型和所需特征数。
- 精确、插值和边缘填充波段数。
- 源波段范围、目标波长范围和中文建议。

### 判定规则

| 判定项 | 兼容 | 警告 | 不兼容 |
|---|---|---|---|
| 模型文件 | 存在且可加载 | 元数据不完整 | 文件缺失或输入类型不支持 |
| 作物 | 项目作物匹配 | 不匹配或无法确认 | 不适用硬性阻断 |
| 传感器 | 强证据匹配 | 证据不足或不匹配 | 明确冲突 |
| 波段 | 完整覆盖目标 | 需要插值或少量边缘填充 | 目标波段完全不可获得 |
| 输入特征 | 维度一致 | 不适用 | 维度不一致 |

单幅和批量接口在服务端重复执行兼容性检查。前端警告不作为唯一安全边界。用户忽略警告时必须显式设置 `force`，结果摘要保存该标志和被忽略的警告。

模型文件 SHA-256 在导入和结果追溯中保存。结果记录模型 ID、名称、版本、算法、训练波长、输入类型、合成数据标记、预处理配置哈希、重采样统计和单位。

## 预处理算法设计

| 算法 | 公式或方法 | 输出 |
|---|---|---|
| 反射率转换 | `R = DN / scale` 或 `R = DN × coefficient + offset` | 地表或表观反射率 |
| Savitzky-Golay | 局部多项式最小二乘平滑 | 降低随机噪声 |
| 波段对齐 | 按源中心波长线性插值；边缘采用最近波段 | 统一波长光谱栈 |
| NDVI | `(NIR - Red) / (NIR + Red)` | 归一化植被指数 |
| NDRE | `(NIR - RedEdge) / (NIR + RedEdge)` | 红边归一化指数 |
| CIredge | `NIR / RedEdge - 1` | 红边叶绿素指数 |
| GNDVI | `(NIR - Green) / (NIR + Green)` | 绿光归一化指数 |
| 云检测 | `Blue > threshold` | 简单云掩膜 |

波长对齐返回 `source_range`、`target_range`、`exact_bands`、`interpolated_bands`、`edge_filled_bands` 和 `edge_fill_ratio`。结果页和 PDF 使用这些字段说明数据是否经过外推。

## 模型推理设计

模型输入分为植被指数特征和光谱矩阵两类。

- 植被指数模型按中心波长选择波段并计算特征。
- 光谱模型先将影像波段重采样到训练波长。
- `(B,H,W)` 在每个行块转换为 `(N,B)`。
- 掩膜外像元输出 NaN，不参与统计。
- 模型预测值限制在软件安全范围内，该范围不替代适用域判断。

平台支持 scikit-learn 风格 `predict` 对象、Pipeline、TransformedTargetRegressor 和单输入 ONNX 模型。自定义模型导入时执行特征数量校验和模拟输入试推理。

### 内置 DNN

| 模型 ID | 输入 | 隐藏层 | 独立测试 R² | 独立测试 RMSE |
|---|---|---:|---:|---:|
| `dnn_nmass_demo` | 400–900 nm，51 波段 | 128、64 | 0.9835 | 0.7398 mg/g |
| `dnn_multispectral_demo` | 5 波段 | 64、32 | 0.7797 | 2.6417 mg/g |

DNN 使用 StandardScaler 标准化特征和目标，Adam 优化，训练、验证和测试集按 80%/10%/10% 划分。指标来自合成数据独立测试集。

## Few-shot 后校准设计

平台将 Few-shot 设计为不修改父模型权重的后校准层，以兼容传统机器学习和神经网络模型。

### 样本配对

用户提交 `sample_id,col,row,nmass`。平台从当前 `nmass_latest.npy` 读取基础预测，并执行范围、重复坐标、像元有限性、实测值正数和单位一致性校验。

无效样点单独返回原因。至少一个有效样点才能生成校正预览。

### 拟合

```text
calibrated = slope × base_prediction + intercept
```

| 有效样点数 | 策略 |
|---:|---|
| 1–2 | 斜率固定为 1，仅拟合偏置 |
| 3–4 | 拟合线性关系，斜率向 1 收缩 |
| 5 个及以上 | 拟合偏置与斜率，斜率向 1 收缩 |

斜率限制为 `0.25–4.0`。平台记录原始拟合斜率、收缩系数、最终斜率和截距。

### 指标

计算校正前、校正后样本内和留一验证的 MAE、RMSE、平均偏差及 R²。

样本内指标不作为独立精度声明；留一指标用于检查少量样点的稳定性。

### 派生模型

派生模型保存在 `data/models/<model_id>/meta.json`，记录父模型 ID、父文件 SHA-256、校正模式、斜率、截距、样点指纹、样点和指标。

派生模型不复制父模型二进制文件。加载时递归解析父模型；父模型文件缺失或循环引用时模型不可用。删除自定义父模型前检查派生模型引用。

### 当前结果更新

应用校正前把当前 `latest.json`、`nmass_latest.npy`、GeoTIFF 和预览复制到 `results/calibration_sources/<model_id>/`。

派生模型通过后台任务重新反演当前影像。结果追溯记录父模型、校正系数、样点和指标。若派生模型继续派生，推理按校正链从基础模型向外依次应用。

## 结果统计与报告设计

统计范围为有效掩膜像元。输出数量、有效比例、均值、标准差、变异系数、最小/最大值、P5/P25/P50/P75/P95 和 30 箱直方图。

分级规则：

- 低氮：`value < low`。
- 适宜：`low ≤ value ≤ high`。
- 高氮：`value > high`。

专题图支持固定分级色带和连续色带。PNG 包含图例、比例尺和指北针；PDF 包含项目信息、管理建议、统计、专题图、直方图和模型参数。

## 前端设计

前端采用本地 Vue 3，不使用构建步骤和 CDN。

- `app.js` 负责页面路由和组件组合。
- `store.js` 保存项目和模型状态。
- `api.js` 封装请求。
- `components` 提供布局、弹窗、图表和 Canvas。
- `pages` 实现六个业务页面。

影像画布基于原生 Canvas 完成点选、矩形框选、缩放和漫游。ECharts 用于光谱、直方图和趋势图。

## 后台任务设计

预处理和反演运行在线程池中。任务保存排队、运行、完成或失败状态，以及进度、阶段、消息和耗时。

服务层将长流程拆分为：

```text
加载数据 → 模型准备 → 自动预处理 → 逐块推理 → 统计分级 → 保存结果
```

任务状态驻留内存，服务重启后不会恢复。任务列表对完成记录有数量上限。

## 异常处理与数据安全

- 项目、影像和模型不存在时返回统一 404 提示。
- 参数、文件格式、波段数量和阈值错误返回中文 400 提示。
- 未处理异常返回 500 响应并在服务端打印堆栈。
- 项目路径使用 ID 白名单校验。
- 删除操作验证目标目录位于项目根目录内。
- 默认仅监听 `127.0.0.1`。
- 影像和结果不上传外网。
- pickle/joblib 导入要求用户确认可信来源。

## 设计边界

- 多期影像自动配准未实现。
- Few-shot 当前采用偏置/收缩线性后校准，不直接更新父模型全部权重。
- PROSAIL/LES 反演未实现。
- 大影像金字塔瓦片未实现。
- 矢量田界裁剪未实现。
- DJI、Headwall、SPECIM 等厂商私有侧车未全部适配。
- 内置模型只代表合成数据示例。
