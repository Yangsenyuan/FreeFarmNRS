## 软件概述

农田氮素遥感监测与反演平台面向农田植被氮素含量 Nmass 的遥感监测。平台把多光谱、高光谱或卫星影像处理为可浏览、可统计和可导出的氮素空间分布结果，为田块长势检查、变量施肥分区和科研分析提供统一的本地处理流程。

平台采用浏览器界面，核心服务运行在用户本机。影像、元数据、模型、预处理光谱栈、反演栅格、专题图和报告均保存在项目目录中，不依赖云数据库，也不把影像上传到外部服务。

软件的核心流程为：

```text
项目管理
→ 数据导入
→ 影像查看
→ 数据预处理
→ 模型反演
→ 结果分析与报告导出
```

## 软件定位

平台将不同传感器、不同波段的影像统一到模型可使用的光谱网格，并把模型适用性、波段对齐、有效像元、分级阈值和结果来源显式展示给用户。

软件既支持无需额外编程的内置示例模型，也允许导入基于实测数据训练的自定义模型。平台负责模型推理和数据追溯，不在当前影像上重新训练模型。

## 项目管理与本地存储

每个项目使用独立目录保存数据。`project.json` 记录项目名称、作物、地点、备注、影像列表、处理状态和最新结果摘要；`logs/project.jsonl` 记录导入、预处理、反演和导出等事件。

单幅影像目录包含原始文件、预处理结果和反演结果。预处理结果保存光谱栈、掩膜、植被指数、预览和质量检查；反演结果保存 GeoTIFF、NumPy 数组、专题图、最新摘要和导出文件。

项目目录可整体备份和迁移。删除项目或影像会删除对应本地目录，因此操作前应完成备份。

## 数据导入与元数据识别

平台支持 GeoTIFF 和 ENVI 影像。ENVI 导入需要同名 `.hdr` 与 `.dat`、`.img`、`.bil` 或 `.bsq` 数据文件。批量导入可一次选择多幅影像和对应侧车文件。

元数据解析器支持以下来源：

- ENVI 头文件。
- GeoTIFF 数据集标签和单波段标签。
- GDAL AUX XML。
- 通用 JSON 元数据。
- MicaSense 结构 XMP 测试样例。
- PlanetScope PSScene STAC JSON 和产品 XML。
- 文件名中的日期和光谱类型线索。

解析结果不仅保存字段值，还保存来源、置信度、原始键名和原始值。用户手动修改的字段优先级最高。重新解析头文件时，系统展示新旧值对比，不静默覆盖人工值。

## 影像查看与光谱查询

影像查看页支持真彩色、假彩色、单波段灰度、伪彩色和卷帘对比。RGB 通道可按中心波长自由选择。画布支持缩放、漫游、全屏、像元点选和矩形区域框选。

点击像元后，右侧显示该像元的反射率或原始值随波长变化的曲线。区域框选计算有效像元平均光谱。多点模式最多同时叠加五条曲线，用于比较作物、土壤和异常区域。

卫星影像的日期标签显示为“采集日期”。信息面板可查看传感器、仪器、Scene ID、空间分辨率、坐标系、数据类型和元数据来源。

## 数据预处理

预处理流程按用户配置依次执行：

1. 反射率转换。
2. 坏波段剔除。
3. Savitzky-Golay 光谱平滑。
4. 波段对齐和重采样。
5. 云像元与植被掩膜。
6. NDVI、NDRE、CIredge、GNDVI 等植被指数计算。
7. 质量检查和预览生成。

反射率转换支持比例因子、定标系数与偏移。波长对齐采用线性插值，超出源影像波长范围的目标波段使用最近边缘波段填充。处理结果保存插值波段数、边缘填充波段数和填充比例。

植被掩膜默认以 NDVI 0.35 为阈值。云检测采用蓝光阈值法，只适用于简单场景。ROI 当前为矩形行列范围，不支持矢量边界。

平台支持以下模型：

| 模型 | 算法 | 输入 | 状态 |
|---|---|---|---|
| 通用 Nmass-NDRE/NDVI 经验模型 | 植被指数回归 | NDRE + NDVI | 合成数据示例 |

| 小麦 Nmass-随机森林模型 | 随机森林 | 51 波段 | 合成数据示例 |
| 通用 Nmass-SVR 模型 | SVR | 51 波段 | 合成数据示例 |
| 全谱 51 波段 Nmass-DNN | 两层 MLP | 51 波段 | 合成数据示例 |
| 五波段 Nmass-DNN | 两层 MLP | 5 波段 | 合成数据示例 |
| PlanetScope Nmass 流程演示模型 | DNN 示例权重复用 | 51 波段 | 仅流程演示 |

| 五波段 Nmass-DNN | 0.7797 | 2.6417 mg/g |

## 模型适用性预检

服务端对单幅和批量反演执行统一适用性检查，检查内容包括：

- 模型文件和输入类型。
- 项目作物与模型适用作物。
- 传感器类型和识别证据。
- 模型输入特征数。
- 影像和预处理结果是否具备所需波段。
- 精确匹配、插值和边缘填充的波段数量。
- 影像是否已经预处理。

硬性不兼容会阻止执行。一般警告必须由用户显式确认后才能继续。批量反演开始前逐幅显示兼容性表，任意影像硬不兼容时默认拒绝。运行态会再次校验，避免只依赖前端状态。

结果摘要记录模型 ID、名称、版本、算法、文件 SHA-256、训练波长、重采样统计、预处理配置哈希、实际单位和强制忽略的警告。

## 自定义模型

平台支持 `.pkl`、`.joblib` 和单输入 `.onnx` 模型。导入时填写名称、算法、训练波长、适用作物、传感器、单位、版本、低氮/高氮阈值、R²、RMSE 和说明。

导入流程检查：

- 训练波长至少两个且严格递增、无重复。
- 模型可加载并具有预测能力。
- 模型输入特征数与训练波长数一致。
- 模拟输入可产生数量正确的单值序列。
- 输出不含 NaN 和 Inf。

模型文件 SHA-256、试推理状态和文件大小写入模型元数据。pickle/joblib 加载存在代码执行风险，只应导入可信来源文件。

## Few-shot 实测校正

平台支持在基础模型完成当前影像反演后，使用少量带有实测 Nmass 的像元样点进行后校准。该能力统一适用于植被指数回归、PLSR、随机森林、SVR、DNN 和用户导入模型。

实测样点可使用 `sample_id,col,row,nmass`，其中 `col` 和 `row` 是预处理结果栅格的 0 基列号和行号；也可使用 `sample_id,lon,lat,nmass`，平台按 WGS84 经纬度和当前结果 CRS 转换为像元坐标。随后平台读取对应像元的基础预测值，并检查样点是否位于有效植被像元。

校正策略根据有效样点数确定：

| 有效样点数 | 校正方式 |
|---:|---|
| 1–2 | 仅偏置校正，斜率固定为 1 |
| 3–4 | 斜率向 1 收缩的保守线性校正 |
| 5 个及以上 | 偏置和斜率的后校准 |

平台计算校正前、校正后样本内和留一验证的 MAE、RMSE、偏差及 R²，并保存拟合斜率、截距、原始斜率和收缩系数。斜率限制在 0.25–4.0，避免少量样点产生极端映射。

应用校正后生成 `few_shot_calibrated` 派生模型。该模型不复制父模型二进制文件，也不修改父模型权重；模型元数据记录父模型 ID、父模型哈希、样点指纹、校正系数和评估结果。校正前结果摘要、Nmass 数组、GeoTIFF 和预览保存在 `results/calibration_sources/<model_id>/`。

派生模型可以用于后续影像，但其适用范围仍受原作物、传感器、地点和时间条件限制。Few-shot 后校准不能替代基于大样本实测数据的独立训练与验证。

## 结果分析与导出

平台以有效掩膜像元为范围计算数量、有效比例、均值、标准差、变异系数、最小值、最大值和分位数。分级规则为低氮 `< low`、适宜 `[low, high]`、高氮 `> high`。

专题图支持分级色带和连续色带，点击像元可查询 Nmass 和等级。直方图显示有效像元分布、均值线和阈值线。多期对比根据日期展示均值趋势、标准差误差线和适宜区间。

PNG 专题图包含图例、比例尺和指北针。PDF 报告包含项目信息、管理建议、统计指标、专题图、分级面积、直方图、模型参数和结果追溯信息。

Few-shot 结果额外记录父模型、校正模式、斜率、截距、样点数、单位和校正指标。

## PlanetScope 真实数据案例

V1.0 使用用户提供的 PlanetScope PSScene 8 波段地表反射率裁剪影像进行本地展示。

| 项目 | 内容 |
|---|---|
| Scene ID | `20251011_032408_70_24da` |
| 传感器 / 仪器 | PlanetScope / `PSB.SD` |
| 采集时间 | 2025-10-11 03:24:08 UTC |
| 地点 | 广东省惠州市惠城区恒福菜场（用户指定） |
| 尺寸 | 689 × 418，8 波段 |
| 空间分辨率 | 约 3 m |
| 坐标系 | EPSG:32650 |
| 中心波长 | 442、490、531、565、610、665、705、865 nm |

平台从 STAC JSON 读取 0.0001 反射率缩放因子，完成反射率转换、光谱对齐、NDVI 掩膜和 DNN 流程反演。原始 8 波段对齐到模型 51 波段时，精确匹配 2 个、插值 40 个、边缘填充 9 个。

示范结果的有效植被像元为 137,512/288,002，占 47.747%；均值 20.944 mg/g；低氮、适宜和高氮占比分别为 39.802%、59.791% 和 0.407%。该结果使用合成示例模型，只用于验证软件流程。

同一 Scene 的简化 JSON 与产品 XML 云量分别为 0% 和 31.27%。平台保留双来源并提示人工确认。

## 当前边界

- 不实现多期影像自动空间配准。
- 不直接更新父模型的全部内部权重；Few-shot 采用偏置/斜率后校准。
- 不实现 PROSAIL/LES 辐射传输反演。
- 不实现大影像金字塔瓦片引擎。
- 不实现矢量田块边界裁剪。
- 云检测采用蓝光阈值法。
- 尚未逐一适配 DJI、Headwall、SPECIM 等全部厂商私有侧车格式。
- 内置模型均使用合成数据，不能代表真实田间标定精度。
