## 3.1 Few-shot 实测后校准

- 输入样点：`sample_id,col,row,nmass`，行列采用预处理结果 0 基坐标。
- 1–2 个有效样点采用偏置校正；3–4 个采用向斜率 1 收缩的保守线性校正；5 个及以上拟合偏置与斜率后校准。
- 输出校正前、样本内和留一验证的 MAE、RMSE、偏差及 R²。
- 派生模型保存父模型 ID、父模型 SHA-256、样点指纹、系数、指标和样点，不复制父模型二进制权重。
- 应用校正前将现有结果摘要、Nmass 数组、GeoTIFF 和预览复制到 `results/calibration_sources/<model_id>/`。
- 自动化测试包含真实 `run_inversion` 链路：从基础 Nmass 结果读取样点、创建派生模型、重新反演并校验校正后的栅格。

## 5. 当前明确不支持的格式/能力

- 尚未逐一适配 DJI、Headwall、SPECIM 等厂商全部私有侧车格式。
- 未内置生产级实测 Nmass 模型，PlanetScope 案例没有对应田间氮素真值。
- 未实现多期自动空间配准、父模型全量权重再训练、PROSAIL/LESS、金字塔瓦片和矢量边界裁剪。
- Few-shot 当前是通用后校准，不是对 PLSR、随机森林、SVR 或 DNN 全部权重的更新。
- 单输入 `(N, B)` ONNX 推理继续复用 `onnxruntime`；不支持多输入或带自定义前处理的 ONNX。
